# Western Yellow-billed Cuckoo Proposed Habitat

**June 2020** · Western United States

This map makes the proposed federal critical habitat units for the western yellow-billed cuckoo explorable. Tom Shanks assembled and published the web map for Greenwood Wildlife Rehabilitation, as described in his [original portfolio](https://tom-shanks.github.io/).

[Open the interactive map](https://tom-shanks.github.io/cuckoo_map/). Open **Layers** to toggle the proposed habitat polygons. Select a polygon for its attributes or use the binoculars control to search by unit name.

## Sources and methods

- The [bundled polygon layer](data/PCH_COCCYZUS_AMERICANUS_20200227_1.js) is dated February 27, 2020, matching the [U.S. Fish and Wildlife Service's revised proposal](https://www.fws.gov/species-publication-action/endangered-and-threatened-wildlife-and-plants-revised-designation). The export does not record an original dataset download URL.
- [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) provide the reference basemap.
- QGIS/qgis2web generated the export from the source polygons. Leaflet renders the layer, popups, and unit-name search. The regulatory boundaries came from USFWS.

This is the 2020 proposal. Consult the [April 2021 final rule](https://www.govinfo.gov/content/pkg/FR-2021-04-21/pdf/FR-2021-04-21.pdf) for the later designation. The transferable work is publishing complex polygons with searchable identifiers and tying map interpretation to the source version.
